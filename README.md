# Hangman Game

A simple command-line Hangman game built with Python. Guess the hidden word before running out of lives!

## Features
- Random word selection
- Six lives per game
- ASCII Hangman graphics
- Tracks previously guessed letters
- Option to replay the game

## Requirements
- Python 3.x

## Getting Started

Clone the repository:

```bash
git clone git@github.com:CameronSelb/Hangman.git
```

Navigate to the project directory:

```bash
cd <path/Hangman>
```

Run the game:

```bash
python hangman.py
```

## How to Play
1. Run the game in your terminal.
2. Guess a letter or try to guess the word.
3. Avoid incorrect guesses to keep your lives.
4. Reveal the word before you run out of lives to win!
